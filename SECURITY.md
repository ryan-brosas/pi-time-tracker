# Security

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/ryan-brosas/pi-time-tracker/security/advisories/new), not a public issue.

Include the affected revision, Pi/Bun/Bend versions, operating system and a minimal synthetic reproduction. Never attach real working-hours ledgers, private reports, customer records, credentials or unredacted conversations.

Only the current `main` branch is maintained. This is an early project with no guaranteed response time or supported-release schedule. Receipt auditing checks consistency, not cryptographic authenticity. Note filtering is not a complete data-loss-prevention system; review free-text labels and notes before recording them or sharing output.
